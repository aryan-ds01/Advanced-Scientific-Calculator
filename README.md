
# Python Calculator

## About Project
A Advance Calculator developed using Python and Tkinter.

## Features
- Addition, Subtraction, Multiplication, Division
- Square and Power
- Square Root
- Sin, Cos, Tan
- Log and Natural Log
- Calculation History
- Clear History
- Keyboard Support

## Technology Used
- Python
- Tkinter
- Math Module

## How to Run
1. Install Python.
2. Download the project.
3. Run the following command:

python python_calculator.py
